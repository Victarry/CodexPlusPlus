# Codex++ v1.11.3 · Victarry 无广告 fork

首个独立发行版，基于上游 v1.11.2，包含本机已验证的增强与修复。

## 本版内容

- 移除管理器和注入界面的广告、推荐入口及后台推广请求。
- 分开统计模型与工具调用，显示会话轮次、累计 token、吞吐和缓存命中率；支持显式配置的 SSH 远端统计。
- 修复 SSH 会话身份识别、新会话发送后的统计自动挂载；模型菜单按供应商分组。
- 在归档页选择本机或 SSH 主机，复用原生列表和操作。
- 新增 side chat「保存为正式聊天」：保存完整已加载轮次及工具记录，重新读取核对后打开正式副本；保留原聊天。
- 修复保存按钮行挤出底部输入框的问题。
- 保留 macOS 多开目录隔离及僵尸 worker 识别修复。

## 下载与安装

本次提供 **macOS Apple Silicon（arm64）** 安装包；未提供 Intel、Windows 或 Linux 二进制。源码随标签一并公开。

- `CodexPlusPlus-1.11.3-macos-arm64.dmg`：打开后将 `Codex++.app` 拖到 Applications。
- `CodexPlusPlus-1.11.3-macos-arm64.zip`：解压后将应用移到 Applications。
- `SHA256SUMS.txt`：文件校验值；`BUILD-INFO.json`：源码提交与构建信息。
- `latest.json`：供本 fork 的内置更新检查读取。

这是 **ad-hoc 本地签名、未经 Apple 公证** 的自有构建。首次打开可能需要在「系统设置 → 隐私与安全性」中允许该应用运行。它不具有上游 Developer ID 签名身份。

配置目录和 bundle ID 保持兼容；升级前退出 Codex++ 管理器。若管理器正在转发模型请求，先等待请求结束。官方 Codex 客户端需另行安装。
